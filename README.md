# 🕹️ Jhojan Ramos · CV Arcade 3D

Una hoja de vida interactiva e inmersiva ambientada en una sala arcade 3D construida con Three.js.

## 🚀 Características

- **Entorno 3D Completo**: 4 cabinas arcade interactivas alineadas en una atmósfera cyberpunk retro con niebla infinita, partículas atmosféricas y reflejos en el piso.
- **Estética Cel-Shaded & Flat-Shaded**: Contornos cel-shaded negros, materiales mate, pantallas CRT con scanlines animados y marquesinas iluminadas.
- **Transiciones Cinemáticas**: Dolly zoom hacia la cabina seleccionada con efecto *power-on* de tubo de fósforo.
- **Navegación Móvil Adaptativa**: Posición inicial optimizada, gestos *Swipe*, botones flotantes `◀` `▶` y botón de affordance "Toca para entrar".
- **Accesibilidad**: Navegación por teclado (Tab / Enter) y compatibilidad total con `prefers-reduced-motion`.

## 🛠️ Tecnologías

- **Three.js** (WebGL 3D Rendering)
- **HTML5 Canvas & Vanilla CSS**
- **JavaScript ES Modules**
- **Google Fonts** (*Press Start 2P*, *JetBrains Mono*, *Inter*)

## 📦 Despliegue en GitHub Pages

Este proyecto funciona directamente como un sitio estático sin necesidad de compilación (`build`).
Solo requiere habilitar **GitHub Pages** desde la rama `main` en la raíz `/ (root)`.
